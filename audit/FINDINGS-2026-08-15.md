# Neural Voice Findings — 2026-08-15

Status keseluruhan: **RELEASE BLOCKED**. Semua finding code-level yang ditangani memiliki regression gate, tetapi tidak ada klaim device-fixed sebelum retest iPhone.

## NV-001 — Tidak ada UI pemilihan voice neural
Severity: **CRITICAL** · Status: **FIXED_CODE**

Evidence: Runtime memiliki enam voice lokal, tetapi aplikasi tidak merender selector; default efektif af_heart kecuali caller mengirim voice.

Repair/next action: Tambahkan katalog enam voice, selector persisten di Skills Lab, dan default TTS mengikuti pilihan user.

## NV-002 — Aset sudah prepared tetapi jalur audibility masih browser-first saat runtime belum ready
Severity: **CRITICAL** · Status: **FIXED_CODE**

Evidence: Patch audibility lama memilih browser TTS ketika status.ready=false, sehingga keadaan prepared=true dapat tetap tidak pernah membuktikan neural playback.

Repair/next action: Keadaan prepared=true sekarang mencoba runtime neural terlebih dahulu; browser fallback hanya setelah neural benar-benar gagal dan hanya jika fallback diizinkan.

## NV-003 — Beberapa AudioContext dapat dibuat per sesi bicara
Severity: **HIGH** · Status: **FIXED_CODE**

Evidence: Player dibuat dari beberapa jalur bootstrap/audibility; WebKit membatasi AudioContext dan kegagalan dapat mematikan jalur audio.

Repair/next action: AudioContext dijadikan singleton per environment melalui repair M-020.

## NV-004 — Fallback browser dapat melaporkan sukses walau audio gagal
Severity: **HIGH** · Status: **FIXED_CODE**

Evidence: onerror/timeout sebelumnya resolve sehingga kegagalan audio dapat terlihat sebagai sukses.

Repair/next action: Fallback sekarang reject dan status menyimpan lastFallbackReason.

## NV-005 — AudioBufferSource.start() menelan exception
Severity: **HIGH** · Status: **FIXED_CODE**

Evidence: Exception start sebelumnya ditelan catch kosong; promise dapat berakhir seperti sukses tanpa bunyi.

Repair/next action: Context suspended/interrupted dan start failure sekarang menjadi error eksplisit, memungkinkan neural-only preview gagal dengan benar dan fallback normal mencatat alasan.

## NV-006 — Priming iOS melewati storage preflight
Severity: **HIGH** · Status: **FIXED_CODE**

Evidence: Aset besar dapat mulai diambil sebelum estimasi quota/usage diverifikasi.

Repair/next action: Tambahkan preflightLargeAssets sebelum transfer besar dan fail dengan storage_insufficient bila ruang tidak cukup.

## NV-007 — Progress caching dapat maju walau cache gagal
Severity: **HIGH** · Status: **FIXED_CODE**

Evidence: done(WASM)/done(MODEL) berada di luar verifikasi keberadaan cache.

Repair/next action: Progress hanya maju setelah cache.match mengonfirmasi aset benar-benar tersimpan.

## NV-008 — Service worker dapat membungkus opaque response sebagai 200 body kosong
Severity: **HIGH** · Status: **FIXED_CODE_ADJACENT**

Evidence: Wrapper no-cors lama berisiko membuat SDK cross-origin kosong dan merusak jalur pendukung.

Repair/next action: CORS-first; jika gagal, jangan menyamarkan opaque body menjadi response 200 sintetis.

## NV-009 — Aset neural masih berbagi cache app shell
Severity: **MEDIUM** · Status: **OPEN_DEFERRED**

Evidence: Update versi aplikasi berpotensi menghapus cache neural besar karena activate menghapus cache fiezel-* yang bukan current.

Repair/next action: Belum diubah pada audit ini karena berisiko terhadap bukti device; desain cache voice terpisah tetap pekerjaan lanjutan.

## NV-010 — Belum ada bukti iPhone/PWA standalone
Severity: **RELEASE_BLOCKER** · Status: **PENDING_DEVICE**

Evidence: Source lock masih realDeviceGate=PENDING dan productionClaim=false.

Repair/next action: Jalankan retest device m022-1, ekspor Diagnostics, uji setiap voice dengan tombol Uji neural, dan hanya buka gate bila provider benar-benar neural serta audio terdengar.
